# Reference: https://www.joelonsoftware.com/2000/08/09/the-joel-test-12-steps-to-better-code/
Takeaways from the above article by Joel Spolsky

1. Use source control
2. Make project build in one step
3. Make daily builds
4. Bug Database: Always organize your bug list, instead of keeping them in your head. 
    Bug databases can be complicated or simple. A minimal useful bug database must include the following data for every bug:

    complete steps to reproduce the bug
    expected behavior
    observed (buggy) behavior
    who it’s assigned to
    whether it has been fixed or not
5. Fix bugs before writing new code.
6. Always have a schedule whenever working for a feature
7. Maintain spec - no code without spec
8. Quiet working space
